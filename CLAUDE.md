# WBC for Me

## Project Overview
A static website (plain HTML/CSS/JS, no build step) that shows which players from any MLB team are playing in the World Baseball Classic. Data comes from the MLB Stats API (free, no auth).

## Key Files
- `index.html` — Single-page app structure with multiple screens
- `app.js` — All application logic, API calls, rendering, state management
- `style.css` — Responsive styles with CSS custom properties

## Development
- Local dev: `python3 -m http.server 8080` from project root
- Hosted on GitHub Pages at https://wbcforme.com
- Repo: https://github.com/joshular/WBCforMe
